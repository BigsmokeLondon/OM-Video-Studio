# Test media

Small files for trying the app (for example the Mac tester chart). They were generated with ffmpeg's own test patterns, so they carry no copyright and can be shared freely.

| File | What it is |
|---|---|
| `OM_Test_Clip_A_15s.mp4` | 15 s, 1280x720, test pattern, 440 Hz tone, on-screen timer |
| `OM_Test_Clip_B_10s.mp4` | 10 s, 1280x720, colour bars, 660 Hz tone, on-screen timer (second clip for Join / batch tests) |
| `OM_Test_Photo.jpg` | 1280x720 test picture for the image tools |
