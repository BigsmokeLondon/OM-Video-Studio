# O.M. Video Studio videos

All three have a British English voiceover and no captions.

| Video | Format | Length | What it covers |
|---|---|---|---|
| [01-install-mobile.mp4](01-install-mobile.mp4) | Portrait 1080x1920 | 49 s | **Download and install.** Open the GitHub release page, download `OM-Video-Studio-Setup.exe`, click through the Windows "protected your PC" warning (More info, then Run anyway), run the installer, and say Yes to the one-time ffmpeg download on first launch. The download and install screens are illustrations, not a screen recording. |
| [02-quick-tour-mobile.mp4](02-quick-tour-mobile.mp4) | Portrait 1080x1920 | 66 s | **Quick tour for phones.** Choose a file, pick an output folder, choose a tool from the categories, run it, and find the result. Light mode and text size. |
| [03-full-walkthrough-hd.mp4](03-full-walkthrough-hd.mp4) | Landscape 1920x1080 | 5 min 10 s | **Full walkthrough, recorded at native HD.** Tours the 69 operations across the 9 categories (video, format, audio, combine, text, effects, images, analysis, streaming), with real runs of Trim, Speed, Resize, Crop, Rotate, Flip, Aspect ratio, Stabilise and HLS. |

Video files are best downloaded and played locally; GitHub may not stream them inline.
